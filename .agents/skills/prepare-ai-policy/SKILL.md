# Prepare the shared AI policy

Read the [toolkit instructions](../../../AGENTS.md) and [builder guide](../../../AI/AGENTS.md). Use the [preparation workflow](../../../preparation/README.md) and [decision worksheet](../../../preparation/DECISION_WORKSHEET.template.md) as working material.

## Work toward a usable discussion

- Identify the collaboration, intended manuscript and immediate questions from the available context. Keep the reusable master blank; maintain a project copy in the agreed private location, normally `preparation/sessions/<project>/`.
- Research relevant primary policies, compare alternatives and draft useful options within the current task and environment. An unresolved future scientific permission does not restrict this preparatory work.
- Prioritise the decisions that affect the next real task. Offer short, concrete choices and preserve IDs, conditions, responsible humans and the source of each answer. The catalogue is not a requirement to ask every question in one call.
- Separate personal preferences, proposals, reported shared agreements and observed facts. Record unanswered choices as `?`; a complete-looking form is not evidence of adoption.
- Discuss skill use and maintenance alongside tools, access and authority. A reusable procedure does not create a scientific permission.
- Accept prompts in any language and use the human's preferred conversation language. Write files in English by default unless the human explicitly requests another language for specified files or passages; a prompt's language alone is not such a request. Preserve reported prior AI uses as attributed evidence, separately from permissions.

## Useful result

Leave a readable project worksheet and a brief account of decisions reached, consequential open questions and the next useful discussion. A provisional project agent may be drafted before all answers exist, clearly labelled as such. Ask only for missing information or decisions needed for the next dependent action; continue independent preparation.

This skill prepares the policy. Applying it to a manuscript follows that project's actual access, task scope and adopted rules.
